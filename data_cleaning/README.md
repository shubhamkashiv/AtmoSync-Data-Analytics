# Data Cleaning – AtmoSync

## Objective
To prepare the weather dataset for accurate analysis by identifying and handling data quality issues.

## Planned Tasks

1. Load the raw weather dataset using Python Pandas.
2. Inspect dataset structure and column data types.
3. Identify missing values and invalid entries.
4. Handle placeholder values such as `—`.
5. Convert weather-related columns into appropriate numeric formats.
6. Save the cleaned dataset for further analysis.

## Tools
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Expected Output
A cleaned and validated weather dataset ready for data analysis.
